# Breaking News

Short news summaries on `/breaking-news/`, independent of the desktop agent. No visitor data is sent to OpenAI. The existing Cloudflare Worker owns one SQLite Durable Object named `world-news-v1`; its state contains the last edition, private research evidence, API usage, operational status and monthly reservation ledger. No public write or refresh endpoint exists.

Current discovery reads BBC News, The Guardian, Al Jazeera, WHO South-East Asia and NASA. Selection takes one fresh report per available publisher before repeating sources, up to five stories. A blocked source or one with no fresh reports is skipped. See `docs/news-variety-2026-10-11.md` for adapters, bounds and the reviewed diverse edition. The historical recovery notes below describe completed investigations, not current failures.

## Editorial rules

The current manually reviewed edition is in `lib/news-first-edition.js` (legacy filename). Current review notes and source dates are in `docs/news-variety-2026-10-11.md`; previous editions remain in Git history. It is an editorial selection, not an exhaustive ranking. It is available only while individually fresh, retains a fixed preparation time and never resets dates during deployment. A newer successful automated edition replaces it. The public API reports `manual-edition` and a separate `automationStatus`, so a manual publication cannot conceal an automatic failure. No paid research call or storage/budget reset is needed for manual publication.

Verified live publisher metadata and short source excerpts only. At most five distinct stories, original short English prose, simple titles, direct HTTPS source links and honest dates. This is an editorial selection, not an objective ranking of the world's five most important events. Attribute allegations and opinions; a politician's claim is not an established fact. The source link and date come from the actual publisher response, not the model's JSON. Reject unavailable publisher data, incomplete responses, unknown source IDs, unsafe text, invalid dates and empty results. Evidence and usage stay private. Automated grounding reduces mistakes but does not prove each generated sentence; periodically review editions against their sources and correct errors. Legacy search parsing helpers remain for regression tests and historical diagnosis, not the runtime refresh.

At every render, remove stories reported 48 hours ago or earlier, future-dated stories and stale editions. If there are no valid stories, omit the homepage block rather than inventing or promoting stale news. On API failure keep the prior edition with its original date. The date shown is the last successful edition, never a failed attempt. No publisher feeds, images or copied paragraphs are imported.
