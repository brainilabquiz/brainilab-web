# Review YouTube promotions for BrainiLab Growth

Start with the current `videoResearch` handoff, draft registry and both pack libraries listed in the Growth workflow. Resume a suitable draft before preparing another. Check the channel's uploads and scheduled videos in YouTube Studio. Read the existing production calendar in Google Sheets when the exact workbook and relevant dates can be verified. Use the native schedule for scheduled uploads and the planning calendar for work still in production. Record the source, observation time, range and coverage gaps in the private review notes. Set `currentUploadReview` and `currentCalendarReview` to `true` only for completed checks. Reuse matching captures with their original dates. When coverage is incomplete, leave the review pending and preserve the prepared drafts.

Use Studio for BrainiLab channel metrics and audience observations. Check channel `UCy35EdjSpdYufOLJBybevsA`, period, format and the age of the videos being compared. Preserve the original Studio snapshot and separate long-form videos from Shorts. If checking the existing vidIQ connection is useful, its channel listing can verify the same channel without credits. Check tool cost before research. Use paid vidIQ tools only for a specific question covered by an explicit research budget. A channel listing establishes account access. Demand or audience claims require evidence from the relevant report.

Compare the proposed topic and format with existing drafts, published and scheduled videos. Look for a reason a viewer of the proposed video would want to play the existing game. Verify the exact destination and, when applicable, the tagged link. Use [pilot measurement](../growth-pilot-measurement/SKILL.md) to choose a measure the existing data supports. Keep YouTube views, website sessions and recorded starts separate.

Record whether to resume, prepare or defer, with the evidence and the reason. Use the draft-only workflow in `tools/growth/README.md` for any pack that is ready. Existing publication, scheduling, spending and permission boundaries apply.
