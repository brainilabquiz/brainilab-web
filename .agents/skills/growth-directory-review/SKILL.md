# Directory review for BrainiLab Growth

Start with one public game or collection and the audience it serves. Read the current outreach register, exclusions and recent directory receipts before qualifying a candidate. Resolve aliases, old domains, duplicate submissions, existing listings, uncertain sends and `doNotRetry`. Reuse a saved observation with its original date when the question and scope match.

- **Qualify a candidate.** Check the portal's current rules and a representative listing. Record the audience fit, playable original URL, accepted game type, editorial or community listing route, cost, and any required account, media, rights, embed or reciprocal link. If a requirement exceeds existing authorisation, leave the item pending with the specific dependency. A channel can be useful for direct discovery even when it offers little search visibility.
- **Verify a listing.** Record the final public listing URL, access mode, observed status and date. Inspect the actual outbound anchor, exact `href`, `rel` and destination. Record indexing signals for the listing separately, including a robots meta tag or HTTP header when available. When asked whether a directive is typical, compare peer listings of the same type and report the scope of the sample. Schema, an HTTP 200 and an outbound link are separate observations.
- **Follow up in Growth.** Keep submission receipt, public listing, verified HTML or rendered link, indexing eligibility and measured referrals separate. Match Analytics referral observations to their actual host, scope and period. Claim a particular listing or landing path only with evidence at that scope. Keep a previous observation if a fresh check fails and label it with its original date.

Record the concrete next action and the evidence that supports it. Preserve the outreach hold and existing approval for each submission or message. This review grants no permission to send, retry, accept terms, buy placement or grant embedding rights. Reserve an authorised attempt in the private ledger and reconcile its receipt there. Only allowlisted public listing evidence and aggregate counts go into Growth or SEO Explorer.
