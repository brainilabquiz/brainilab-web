# Order Up quality repair — 15 October 2026

Eight original Order Up rounds compare exact fractions, decimals, percentages, signed numbers, durations, single calculations, metric lengths and masses. Each has ten unique labels and strictly increasing rational values in one declared comparison unit. Eight Odd One Out questions name an explicit mathematical rule, with exactly one failing item and a brief explanation. OpenStax sources explain the methods; the examples are original, not copied exercises. These are game records, not Learn articles.

The build now runs tools/validate-game-batches.mjs. New Order Up batches need comparable sort values and cannot contain ties, reversals or label/value mismatches. Maths and measurement labels are evaluated exactly. Future factual ordering batches must provide a strict comparable value and source evidence for every card; a successful build cannot verify the truth of an external factual claim by itself. Mathematical Odd One Out questions require a testable rule; other questions require per-item fact checks. Admin CSV round-trips use the real parser and normaliser.

Seven existing Order Up rounds are placed on editorial hold, not deleted. Nobel categories contain tied 1901 years and other award schemes; ancient wonders and the Grand Slam calendar contain cards outside the stated category; the sleep chain mixes stages with overlapping/repeated events. Crust abundances mix an atom-count label with no consistent metric. River lengths and average animal masses lack comparable source values/definitions. These last cases remain on hold for documented comparison data; no unsourced replacement ranking is asserted. The blocked Smithsonian source is recorded as unavailable, not claimed as checked.
