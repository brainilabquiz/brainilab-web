    How to play Number Route

    Keep the four numbers where they are and choose the three signs between them. Each step uses your running total. Use every number, even if you reach the target early.

    Try this route: 7, 3, 6, 4 → 28

    1. 7 − 3 = 4. Start by subtracting.
    2. 4 × 6 = 24. Multiply your running total.
    3. 24 + 4 = 28. Add the last number to reach the target.

    This game calculates strictly left to right, unlike ordinary written arithmetic. There is one solution per puzzle, and division must give a whole number.

    Take a wrong turn?

    Reset the route to try different signs, or skip to the next puzzle. In Anytime play, fewer attempts earn more points. Read the Number Route guide for another example.

    Is Number Route part of the Daily?

    Yes, it can appear in the rotating Daily challenge. Daily rounds have three routes and reward quicker solves. Anytime rounds have ten routes. The optional “Try first” round is practice and does not add points.
