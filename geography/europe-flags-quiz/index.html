Two flags, one useful difference

France and the Netherlands both use blue, white and red. Look at the stripes: France’s stand upright; the Netherlands’ run across. Start with that shape before you try to remember the country.

Try describing a flag out loud before choosing an answer. After the round, return to the ones you mixed up. You can play again with the questions and choices in a different order.

Which countries are in this quiz?

This starter set covers 20 European countries, not every country in Europe. Europe and the European Union are different groups: Norway and Switzerland are in this set too.

Austria, Belgium, Bulgaria, Switzerland, Czechia, Germany, Denmark, Spain, Finland, France, Greece, Hungary, Ireland, Italy, Netherlands, Norway, Poland, Portugal, Romania, Sweden.

Regional reference: United Nations M49 geographical regions. Flag artwork uses the same local assets as World Flags.
